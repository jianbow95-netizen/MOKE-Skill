# 三十 · 创作画布 2.0

可连接、可分项目管理的私人无限画布。通过 ChatGPT 内置 imagegen 执行图片生成，不配置第三方生图 API。

## 创作方式

1. 新建项目，上传图片，添加文字与提示词节点。
2. 拖动节点右侧输出圆点到另一节点；也可按 C 依次点击起点与终点。
3. 图片与文字连到提示词节点，在右侧编辑提示词和画幅，点击生成。
4. 新的输出节点自动连接到提示词，收集上游图片与文字。
5. 点击「处理任务」，将指令发送到已连接此画布的 ChatGPT 对话。ChatGPT 领取任务、查看参考图、调用内置 imagegen，并将真实图片回传原项目。

已完成的输出节点可作为下一轮的图片输入。生成输入使用该输出图片，不自动追加它更早的参考图。未生成的上游输出会阻止后续任务提交，避免缺失图片的错误生成。

网页不会自行唤醒 ChatGPT；生成仍由活动 ChatGPT 会话执行。未处理任务会保持「等待处理」，不假装正在生成。

## 已实现

- 多项目：新建、切换、重命名、复制、删除；节点、连线、分组、历史分别保存。
- 节点：图片、可编辑文字、提示词、生成输出；重命名、色彩、锁定、尺寸调整。
- 连线：拖动端口或点击连接；箭头、标签、选择、删除；防止循环；自动汇集上游输入。
- 选择：单选、Shift 多选、框选、全选、多节点拖动。
- 整理：分组与组内移动、取消分组、对齐、等距、网格排列、16px 网格吸附。
- 复制：节点副本、Ctrl+C/V，以及跨项目粘贴，保留选中节点内部连线。
- 历史：每项目撤销重做，保留异步生图的真实完成状态与图片。
- 导航：手形平移、Space 临时平移、鼠标位置缩放、查看全部/选中、小地图导航。
- 素材：拖入/粘贴图片、搜索与类型筛选、下载原图。
- 项目迁移：导出包含图片、连线与分组；导入为独立项目；兼容旧版文件。
- 保存：R2 持久保存，条件写防止并发覆盖；每项目保存浏览器视角偏好。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 选择 / 平移 / 连线 | V / H / C |
| 添加提示词 / 文字 | P / N |
| 临时平移 | Space + 拖动 |
| 查看全部 | F |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 全选 / 创建副本 | Ctrl+A / Ctrl+D |

| 将节点分组 | Ctrl+G |
| 删除 | Delete |
| 取消连线或选择 | Escape |

Mac 使用 Command 代替 Ctrl。

## 开发与验证

```sh
node scripts/assemble.mjs
node scripts/test.mjs
node scripts/test-v2.mjs
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

- `page.html`：网页与交互。
- `core/canvas.js`：画布几何、输入收集、循环检测与图关系重映射。
- `worker/server.js`：R2 项目存储、历史、任务与 MCP 接口。
- `worker/index.js`：组装生成的单文件 Worker。
- `scripts/test-v2.mjs`：完整创作场景验证，包括任务跨项目回传、生成中编辑及撤销保护。

部署需要 R2 `BUCKET` 和可信身份网关。Sites 私人站点负责浏览器登录、MCP OAuth 与服务访问鉴权。`/api/agent` 仅适用于平台鉴权的 owner-private 站点；不得将这个服务作为公开匿名站点部署。

GitHub 仅保存源码，不保存私人素材、提示词、运行记录或服务凭证。旧版画布在首次写入时迁移到「默认项目」，保留节点 ID、图片 ID 与原任务状态。

每项目最多 500 个节点与 1500 条连线，单张图片最多 15 MB，参考图最多 10 张。历史最多 40 步并按项目大小限制内存；导入导出素材总量最多 38 MB。

## MCP 生图协议

`canvas_list_projects` → `canvas_get_board` / `canvas_list_tasks`（可指定 project_id） → `canvas_claim_task` → `canvas_read_asset` → 会话内置 imagegen → `canvas_complete_image`。

任务只会回传到所属项目。失败调用 `canvas_fail_task`。不得使用占位图或伪造成功。

### 画布界面更新

图片下方展示该图的生成提示词，长提示词可滚动阅读和选中文字。上传素材没有生成提示词时会明确标注。拖动输出端口到空白处，可选择创建提示词、文字或上传图片，并自动连接原模块。项目管理收进左上角下拉菜单；当前项目节点列表默认隐藏，点击顶部“节点”按钮打开。编辑面板仅选中模块、连线或分组后显示，点击空白或关闭按钮收起。
